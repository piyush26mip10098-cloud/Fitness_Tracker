# Fitness & Habit Tracker

## Problem Statement

Maintaining a consistent fitness routine can be difficult when workout
records and daily habits are not properly tracked. Users may find it
difficult to monitor their workout frequency, workout duration,
calories burned, and habit completion.

The Fitness & Habit Tracker provides a simple Python-based solution
for recording workouts, tracking fitness habits, storing data, and
generating progress statistics.

## Scope of the Project

The project focuses on basic personal fitness tracking.

The system allows users to:

- Record workouts
- View workout history
- Delete workout records
- Create fitness habits
- Mark habits as completed
- View overall fitness statistics
- Generate fitness reports
- View weekly workout progress
- Store fitness information using JSON

The project is designed as a console-based Python application.

## Target Users

The target users are:

- Students
- Beginners starting a fitness routine
- Individuals who want to maintain basic workout records
- Users interested in tracking daily fitness habits

## High-Level Features

1. Workout Management
2. Fitness Habit Tracking

# 🏋️ Fitness & Habit Tracker

## 📌 Overview

Fitness & Habit Tracker is a console-based Python application that
helps users record workouts, track fitness habits, monitor progress,
and generate fitness reports.

The project demonstrates modular programming using Python functions,
multiple modules, JSON file handling, input validation, and automated
testing.

---

## ✨ Features

- Add workouts
- View workout history
- Delete workouts
- Add fitness habits
- Mark habits as completed
- View fitness statistics
- Generate fitness reports
- View weekly workout progress
- Store data using JSON
- Validate user input
- Handle invalid input safely

---

## 🛠️ Technologies Used

- Python
- JSON
- Python `datetime`
- Python `unittest`
- File Handling
- Git & GitHub
